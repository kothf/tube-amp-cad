Board Design: help

The board takes its parts and connections from the schematic in the Circuit CAD, which keeps the layout in the circuit file (File → Save there). New parts wait in a row below the board: drag them onto it. Thin lines (the ratsnest) show connections still to route; route them as tracks on the top or bottom copper. The design-rule check lists clearances that are too small (by the voltage between the nets, IPC-2221B), shorts, copper off the board and parts not placed yet, and warns about valve layout: grid stoppers away from the socket, grid tracks alongside anode or heater tracks, electrolytics near hot parts, sockets without a mounting hole nearby. The heaters are wired too: their pins sit on heater nets fed from the heater supply XH1 (Board ▾ → Design rules… sets how).

Auto-route sends the open connections to Freerouting running on this computer and adds the tracks it finds; the button is grey until Freerouting answers (Board ▾ → Freerouting… shows the command that starts it). It keeps the design rules, by voltage too: what it cannot route that way stays in the ratsnest for you. Ctrl+Z takes it all back. Unroute removes every track and via (locked ones stay), again one step for Ctrl+Z.

Freerouting

Auto-route sends the board to Freerouting's API server, on this computer or another one on your network, and adds the tracks it sends back. The board goes nowhere else.

Address (IP or name, :port)

Start it with Java 25 and freerouting.jar


      
or with Docker

      

      
On another computer, Freerouting must listen on the network (the Docker command does; with Java add --api_server.endpoints=http://0.0.0.0:37864). From an https page a browser may refuse a plain http address on another computer (Chrome asks once to allow the local network); then forward it so it looks local: ssh -N -L 37864:127.0.0.1:37864 user@that-pc and keep 127.0.0.1:37864 here.

      

    

  

  

    

      
Design rules

      
Valve circuits run at several hundred volts: nets above the high-voltage threshold (from the simulation) get the HV clearance and the power-track width. Every net belongs to a class: automatically (HV by voltage, GND is Power, the rest Signal) or as you set it below.

The copper prints at 1:1 when the board fits A4 or A3. In the print dialog choose Actual size (100 %, no fit to page), then check that the bar under the board measures 50 mm. For toner transfer use a laser printer, glossy paper and the darkest setting.
